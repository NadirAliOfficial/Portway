# Portway

Portway is a native macOS application that lets users create and manage isolated Wine "bottles" and run Windows executables inside them. It provides a simple GUI built on top of Apple's Game Porting Toolkit, avoiding the abandoned‑project baggage of other Wine wrappers.

## Why

Existing Wine GUIs for macOS are either unmaintained (e.g., Whisky) or paid (CrossOver). Portway offers an actively developed, from‑scratch alternative that integrates directly with the Game Porting Toolkit.

## Features

- Create and delete isolated Wine bottles (separate Windows environments)
- Run any `.exe` inside a chosen bottle
- Browse a bottle's `C:` drive from Finder

## Requirements

- macOS 14+ (Apple Silicon)
- Game Porting Toolkit: `brew tap gcenx/wine && brew install --cask gcenx/wine/game-porting-toolkit`

## Installation

```sh
swift build
swift run
```

The project uses Swift Package Manager; all dependencies are declared in `Package.swift`.

## Configuration

Portway does not require any environment variables at runtime. Future configuration may be added as needed.

## Usage

After building, run the app with:

```sh
swift run Portway
```

Or launch the packaged app bundle generated by `Scripts/build_app.sh`:

```sh
./Scripts/build_app.sh
```
